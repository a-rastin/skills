# Persian and XeLaTeX Rules

## Assumptions

For Persian input, assume the target document is compiled with XeLaTeX and already loads `xepersian`. The converter normally returns only body code.

Do not add a preamble unless explicitly asked. In particular, do not invent font names or emit `\settextfont` automatically.

## Unicode preservation

- Keep Persian and Arabic-script letters as Unicode.
- Preserve the exact code points supplied when possible.
- Preserve zero-width non-joiner (`U+200C`) used for Persian نیم‌فاصله.
- Do not replace نیم‌فاصله with a normal space, hyphen, or explicit TeX command.
- Preserve Persian digits (`۰۱۲۳۴۵۶۷۸۹`) and Latin digits (`0123456789`) exactly as supplied.
- Do not normalize Arabic `ي`/`ك` to Persian `ی`/`ک` unless the user separately requests orthographic correction.

## Directionality

- Ordinary Persian body text needs no added `RTL` environment when `xepersian` is active.
- Keep punctuation attached to the phrase it belongs to.
- Wrap a coherent left-to-right span in `\lr{...}` when necessary for stable ordering.

Suitable `\lr{...}` candidates include:

- English acronyms: `\lr{MRI}`
- Software names: `\lr{LaTeX}`
- English multiword phrases: `\lr{machine learning}`
- File names and paths: `\lr{chapter_1.tex}` after safe handling
- Version strings: `\lr{v2.1.0}`

Do not wrap:

- Every isolated Latin letter automatically
- Mathematical expressions already in math mode
- LaTeX commands generated by the converter
- Persian numbers or punctuation merely because Latin text is nearby

## Mixed Persian-English examples

Input:

```text
نرم‌افزار LaTeX برای حروف‌چینی استفاده شد.
```

Output:

```latex
نرم‌افزار \lr{LaTeX} برای حروف‌چینی استفاده شد.
```

Input:

```text
مقدار p کمتر از 0.05 بود.
```

Output:

```latex
مقدار $p$ کمتر از $0.05$ بود.
```

Use math mode here only because `p` and the threshold are explicitly statistical notation. Do not place all prose numbers in math mode.

## Persian punctuation

- Preserve `،` comma, `؛` semicolon, `؟` question mark, and guillemets `«...»`.
- Do not replace Persian punctuation with English punctuation unless asked.
- Preserve colon choice as supplied. In label-description list items, bold the label together with the supplied colon.

## Percent behavior

Without `@percent`:

```text
۲۵%
```

becomes:

```latex
۲۵\%
```

With `@percent`:

```text
۲۵%
```

becomes:

```latex
۲۵ درصد
```

## Persian lists

Use ordinary `itemize` and `enumerate`; `xepersian` handles directionality. Do not reverse source item order.

Example:

```latex
\begin{itemize}
  \item \textbf{سن:} بر حسب سال ثبت شد.
  \item \textbf{جنس:} به‌صورت زن یا مرد ثبت شد.
\end{itemize}
```

## Persian headings

For explicit headings, place Persian text directly in the sectioning command:

```latex
\section{مقدمه}
\subsection{روش بررسی}
```

Do not add manual right-alignment commands around headings.

## Persian scientific text

- Preserve statistical symbols and variables in math mode when clear: `$p$`, `$n$`, `$\beta$`, `$95\%$`.
- If `@percent` is active, a textual percent sign becomes `درصد`; do not apply that replacement inside an explicitly preserved mathematical formula unless the user clearly intends all percent signs to become words.
- Preserve units and scientific abbreviations; use `\lr{...}` only when directionality requires it.
- Do not translate technical terms or select terminology on the user's behalf.
